#### @Entity
- 이게 붙어있는 클래스는 JPA가 관리, 엔티티라 한다. 
- JPA를 사용해서 테이블과 매핑할 클래스는 @Entity 필수
- @Entity(name = "이름"") -> 이건 JPA가 구분하는 이름임,왠만해선 기본값으로 

##### @Table(name = "")
- 테이블 이름을 DB에 쿼리 나갈때 지못하는 대상



### 주의 
운영시에는    
DDL = Create, Update 하지 말것 

Create -> 서버를 껏다 키면 데이터가 날라감   
Update경우   
SQL : ALTER TABLE Member ADD COLUMN email VARCHAR(255);   
이렇게 컬럼을 넣으면 DB가 잠깐 LOCK을 걸수있음.

- 데이터가 적으면 순식간인데,  데이터가 수백만 건이면 오래 걸리고 그동안 다른 요청들이 기다릴 수 있어.  
 

- 실무에서 조심하는 이유: 영한킴피셜 -> 옆부서에서 이걸로 서비스가 몇분간 멈춘적이있었다. 


그래서 개발 초반에는 update로 자동으로 테이블 만들어주고 이렇게 쓰다가
테이블 구조나 어느 정도 확정이 났다싶으면 validation으로 바꾸는게 좋음

#### 여기서 validation이란?   
Java 엔티티 코드랑 실제 DB 테이블 구조가 맞는지 검사만 하는 것
