# 페이지네이션? 

select s from ScheduleSeat s    
이 조회로 10000건의 조회가 발생하면
DB에서 10,000행 조회   
→ 엔티티 10,000개 생성   
→ DTO 10,000개 생성   
→ JSON 10,000개 전송    
이 작업이 의미없이 발생한다 

이런작업이 필요없게 우리는 필요한 부분만 가져오는역할을한다 

SELECT *             
FROM schedule_seat     
WHERE schedule_id = 1     
AND status = 'AVAILABLE'     
ORDER BY schedule_seat_id  
LIMIT 20 OFFSET 0;
20개의 데이터만 받는것이다
 보통이런거는  카드 사용내역에 모든 내용을 가져오기가 그러니까  
최근 사용내역으로 상위 20건만 가져올떄 사용되는것임 
##### 이점 
1. DB 조회량 감소
2. 서버 메모리 감소
3. JSON 변환 비용 감소
4. 네트워크 전송량 감소
5. 응답시간과 장애 가능성 감소
