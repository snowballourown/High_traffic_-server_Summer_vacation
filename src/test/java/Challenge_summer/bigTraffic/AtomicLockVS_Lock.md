### CAS와 Lock의 차이

CAS는 낙관적 동시성 제어 방식에 가깝다.

이유는 값을 바꾸기 전에 현재 메모리의 값이 내가 예상한 값과 같은지 비교하고,
같으면 변경하고 다르면 실패하거나 다시 시도하기 때문이다.

즉 다른 스레드가 값을 바꾸지 않았을 것이라고 기대하고 먼저 비교한다.
다른 스레드가 이미 값을 바꿨다면 CAS는 실패하고 재시도한다.

반면 Lock은 비관적 동시성 제어 방식에 가깝다.

이유는 여러 스레드가 동시에 같은 데이터를 변경할 수 있다고 보고,
먼저 락을 획득한 스레드만 임계 영역에 들어가게 만들기 때문이다.

락을 획득하지 못한 다른 스레드는 대기한다.
따라서 동시에 변경되는 상황을 아예 막고 순서대로 처리한다.
